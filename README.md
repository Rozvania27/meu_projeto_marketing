## 🎯 Sobre o Projeto

O **Marketing Cloud Data & AI Analytics** é um projeto de análise de dados aplicado ao contexto de Marketing Cloud, desenvolvido para explorar como dados de campanhas podem ser transformados em informações relevantes para o acompanhamento de performance e a tomada de decisão.

A solução integra três pilares:

| 📊 Dados | 🤖 Inteligência Artificial | ☁️ Marketing Cloud |
| :---: | :---: | :---: |
| Análise e interpretação de métricas. | Geração de insights com IA Generativa. | Contexto de campanhas e relacionamento. |

O projeto apresenta uma abordagem dual-stack, reunindo uma aplicação analítica em Python/Streamlit e uma interface web estática desenvolvida com HTML, CSS e JavaScript.

---

## 💡 Problema de Negócio

Campanhas de marketing geram dados que precisam ser acompanhados e interpretados para apoiar decisões estratégicas.

A proposta deste projeto é explorar uma solução que permita:

- Centralizar a visualização de indicadores de campanhas.
- Facilitar a interpretação dos resultados.
- Identificar padrões e oportunidades de análise.
- Utilizar IA Generativa como apoio à leitura dos dados.
- Apresentar informações de forma clara, visual e interativa.

> **Foco:** transformar dados de campanhas em insights que apoiem decisões orientadas por dados.

## 🚀 Funcionalidades

- Processamento de dados utilizando Python e Pandas.

## 🚀 Execução Local

### Pré-requisitos

- Python 3.10 ou superior.
- Git.
- Pip.
- Chave da API do Google Gemini, caso a integração de IA esteja habilitada.

### 1. Clone o repositório

```bash
git clone https://github.com/Rozvania27/meu_projeto_marketing.git
```

### 2. Acesse o projeto

```bash
cd meu_projeto_marketing
```

### 3. Crie um ambiente virtual

```bash
python -m venv .venv
```

### 4. Ative o ambiente virtual

**Windows:**

```bash
.venv\Scripts\activate
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

### 5. Instale as dependências

```bash
pip install -r requirements.txt
```

### 6. Execute o dashboard

```bash
streamlit run app.py
```

### 7. Acesse a versão HTML

Abra o arquivo abaixo no navegador:

```text
versao_html/index.html
```

## 🔐 Configuração da API do Google Gemini

Configure sua chave de API utilizando uma variável de ambiente ou o mecanismo de secrets do Streamlit.

Exemplo de variável de ambiente:

```bash
GEMINI_API_KEY=sua_chave_de_api
```

> Nunca compartilhe chaves de API em repositórios públicos. Utilize variáveis de ambiente e mecanismos seguros de gerenciamento de credenciais.

## 🤖 Uso Responsável de Inteligência Artificial

A Inteligência Artificial Generativa foi utilizada como ferramenta de apoio ao desenvolvimento e à exploração de soluções analíticas.

### Aplicações da IA

- Apoio à estruturação de componentes Python/Streamlit.
- Auxílio no desenvolvimento de HTML, CSS e JavaScript.
- Integração com a API do Google Gemini.
- Exploração de insights gerados a partir de dados de marketing.
- Apoio à Engenharia de Prompts.

### Human-in-the-loop

O projeto adota uma abordagem de validação humana, com revisão das implementações, cálculos e resultados analíticos.

O processo inclui:

- Revisão da lógica do código.
- Verificação dos cálculos de métricas.
- Avaliação do tratamento de dados com Pandas.
- Revisão das respostas geradas pela IA.
- Identificação de possíveis alucinações.
- Alinhamento com as regras de negócio.

> A IA atua como suporte ao desenvolvimento e à análise. A validação humana é essencial para avaliar a qualidade e a confiabilidade dos resultados.
